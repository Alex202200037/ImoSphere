# Manual de Utilizador — ImoSphere

## O que é o ImoSphere?
ImoSphere é uma plataforma para gestão de propriedades imobiliárias, clientes, agentes, visitas e transações.

## Como usar
1. **Aceder à aplicação:**
   - Corre o comando `dotnet run` e abre o browser em `https://localhost:5001`.
2. **Navegação:**
   - Usa o menu para aceder a Home, Propriedades, Clientes, Agentes, etc.
3. **Gestão de Propriedades:**
   - Adiciona, edita ou remove propriedades.
4. **Gestão de Clientes e Agentes:**
   - Regista novos clientes e agentes.
5. **Marcação de Visitas:**
   - Agenda visitas a propriedades para clientes.
6. **Transações:**
   - Regista compras/vendas de propriedades.
